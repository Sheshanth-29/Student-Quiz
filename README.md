Student Quiz Application
Project Description

The Student Quiz Application is a simple web-based application that allows students to attempt a quiz and store their scores in a database.
The application is developed using Spring Boot for the backend, React for the frontend, and MongoDB for data storage.

Students can enter their name and roll number, attempt the quiz, submit their answers, and their score will be calculated and stored in the database.
The application also allows viewing all students' scores.

Technologies Used

Backend
Spring Boot
Spring Web
Spring Data MongoDB
Maven
Lombok

Frontend
React.js
JavaScript
HTML
CSS

Database
MongoDB (MongoDB Compass)
Features
Student can enter Name and Roll Number
Students can attempt multiple-choice quiz questions
Automatic score calculation
Scores are stored in MongoDB database
View all student scores

REST API communication between React and Spring Boot
